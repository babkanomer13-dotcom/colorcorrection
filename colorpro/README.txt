ColorPro 1.2.1 — локальная цветокоррекция

Запуск на этом компьютере: ярлык ColorPro на рабочем столе.
Из проекта: .venv\Scripts\pythonw.exe ColorPro.pyw
Автономные установщики: ColorPro-1.2.1-Win10-x64-Setup.exe (NVIDIA/CPU)
и ColorPro-1.2.1-Win7-x64-Setup.exe (CPU, Windows 7 SP1 x64).
Win7-сборка проверена на Windows 10; реальная Windows 7 ещё требует проверки.
Установщики включают Python, библиотеки и модель; ничего скачивать при работе не нужно.

Интерфейс основан на вашем RetushPro: розовые акценты, белая рабочая область.
1. Добавьте фотографии или ZIP (Ctrl+O, выбор нескольких файлов, перетаскивание).
2. В разделе «Настройки» выберите PNG или JPEG 100% (4:4:4) и папку результатов.
3. Нажмите «Обработать серию». Каждый запуск создаёт новую подпапку.
4. Откройте отдельную вкладку «До / после». Выбирайте снимок из списка или
   кнопками назад/вперёд. Сравнивайте рядом или разделителем, приближайте
   оба изображения синхронно, выбирайте лицо. F11 — на весь экран, Esc — назад.
5. «Результаты» открывает папку обработанной серии с report.json.
Пауза и остановка выполняются после текущего снимка. Готовые файлы сохраняются.
Удаление строки из очереди не удаляет исходник или результат с диска.

Модель: V39, эпоха 5, raw-веса (не EMA), без V71 и других поправок.
«raw-веса» — название состояния checkpoint, НЕ поддержка формата камеры RAW.
Контрольная сумма модели:
d5efdc7ab1e12e0a277e244331b32e4164c9be2836479db5782622f7b563bbe1
Весам и рабочему коду сделана отдельная проверяемая копия вне Git-репозитория.
Оригинальный checkpoint и код обучения не меняются.

Поддерживаются 8-битные непрозрачные RGB/L JPEG, PNG, TIFF, WebP и BMP.
JPEG с MPF/MPO-вложениями: обрабатывается основной кадр, как в проверенной V39.
Вспомогательные кадры не экспортируются; оригинальный контейнер не меняется.
RAW камеры, CMYK, прозрачность, 16-битные и многостраничные TIFF/анимации
нужно сначала экспортировать в 8-битный RGB. ZIP не распаковывается по путям
из архива: снимки читаются по одному. Максимум 10 000 фото / 80 Мп / 256 МБ.

Размер сохраняется с учётом EXIF-поворота. ICC преобразуется в sRGB тем же
кодом, что использовался для V39. Выход содержит профиль sRGB и безопасную
часть EXIF без GPS. PNG сохраняет результат точно; JPEG повторно сжимается,
даже при качестве 100%. JPEG: quality=100, subsampling=0, как в RetushPro.
Модель выбирает глобальный инструмент и уровни, не генерирует пиксели,
не замыливает, не ретуширует кожу. Возможные ошибки оттенков V39 сохраняются:
оболочка не является улучшенной моделью и не заменяет визуальный контроль.

Устройство: автоматически, NVIDIA CUDA или CPU. Нет привязки к модели/UUID GPU.
Автоматический режим проверяет доступные NVIDIA-карты и запуск самой V39,
выбирает доступную с большим запасом памяти; при недоступности GPU — CPU.
Загрузка NVIDIA >=90% или менее 512 МиБ свободной VRAM исключает карту из выбора.
Данные загрузки используются при наличии nvidia-smi; без него доступность
проверяется CUDA. Ручной режим GPU не переключается незаметно на CPU.
AMD/Intel GPU пока не ускоряются: на таких ПК используется CPU.
Выбранное устройство записано в report.json.
Обработка по одному снимку, CPU: 2 потока. Ограничения обучения сюда не относятся.
Архив в локальной конфигурации защищён от записи, исходники не перезаписываются.
Обработка полностью локальная: нет сервера, облачной загрузки и расписания.
Обновления: GitHub Releases babkanomer13-dotcom/colorcorrection. Кнопка «Обновления».
Фотографии не отправляются. При запуске — проверка версии не чаще раза в сутки
(можно отключить). Скачивание и установка — только по нажатию пользователя.
Скачанные файлы проверяются по размеру и SHA-256, отдельно для Windows 10 и 7.
С версии 1.3.0 обновления компактные: только изменённые файлы приложения,
без повторного скачивания библиотек и модели. Один Setup.exe подходит и для
первой установки: необходимые компоненты он загрузит и проверит самостоятельно.

Разработка:

  python -m colorpro.launcher --batch <фото> --output <папка> --format PNG --device auto
  python -m colorpro.prepare_local --help
