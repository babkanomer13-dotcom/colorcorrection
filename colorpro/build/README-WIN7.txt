ColorPro — Windows 7, 64 бита

Отдельная сборка для Windows 7 SP1 x64 с системными обновлениями.
Используются Python 3.8, Qt 5.15 и PyTorch 1.13 CPU.
Для первой установки используйте полный Win7-x64-Offline.exe, без докачек.
Маленький Setup.exe предназначен только для обновления установленной программы.
Обычные обновления содержат только изменённые файлы; модель и библиотеки
сохраняются. После установки обработка работает без интернета.
Обновления приложения доступны отдельно от канала Windows 10 через GitHub.
Для них нужен интернет и актуальные корневые сертификаты Windows; при ошибке
сети обработка продолжает работать. Проверка SHA-256 обязательна; TLS не отключается.
Обработка только на CPU. Это те же исходные веса V39, без дообучения.
Интерфейс, белый фон, JPEG 100% 4:4:4 и обработка серии сохранены.
Драйверы и настройки остальных приложений не изменяются.
Рекомендуется 8 ГБ ОЗУ или больше.

ВАЖНО: сборка проверяется на компьютере сборки с Windows 10. Запуск именно
на реальной Windows 7 пока не подтверждён; необходима проверка на целевом ПК.
Windows 7 и её библиотеки устарели. Пользуйтесь только доверенными файлами.

Требуется AddDllDirectory (KB2533623 / KB3063858 либо заменяющий пакет).
Установщик проверяет наличие этой функции. Системные обновления не включены.
Библиотеки VC++ 2019 и downlevel UCRT включены локально, без подмены системных DLL.

Устанавливается отдельно от основной версии: ColorPro Win7.
После установки выполните «Проверка компонентов» из меню Пуск, затем
обработайте несколько JPEG и проверьте результат.
Журнал: %LOCALAPPDATA%\ColorProWin7\logs\application.log.
Диагностика: %LOCALAPPDATA%\ColorProWin7\diagnostics.json.

Исходники не изменяются. Удаление приложения не удаляет ваши фотографии.
Установщик не подписан цифровой подписью. Проверяйте SHA-256 и происхождение.
