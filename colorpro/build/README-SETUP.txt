ColorPro — установка и компактные обновления

Windows 10/11, 64 бита. Для установки достаточно одного Setup.exe.
На новом ПК установщик сам загрузит и проверит библиотеки, Python и веса.
Первичная загрузка компонентов — около 2,5 ГиБ. При обычном обновлении
они сохраняются: скачивается небольшой пакет только изменённых файлов.
Для работы интернет, Photoshop и отдельно установленный Python не нужны.
Интернет нужен для первой установки и скачивания обновлений. Фотографии не отправляются.
Не нужно искать диски или скачивать BIN вручную. Уже установленное приложение
проверяет компоненты перед обновлением; повреждённый комплект не перезаписывается.
Кнопка «Обновления»: проверка, загрузка с SHA-256, установка после завершения серии.
Автопроверку при запуске можно отключить. Автоустановки без нажатия нет.
Права администратора не требуются. Установка — в профиль пользователя.

Автоматический выбор доступной совместимой NVIDIA CUDA или CPU.
Можно явно выбрать GPU или CPU. AMD/Intel используются через CPU.
Драйвер видеокарты должен быть установлен заранее; ColorPro его не меняет.
Рекомендуется 8 ГБ ОЗУ или больше для полноразмерных фотографий.

Добавьте фотографии или ZIP, выберите папку, нажмите «Обработать серию».
Поддерживаются 8-битные RGB/L JPEG, PNG, TIFF, WebP, BMP. RAW и 16 бит — нет.
JPEG сохраняется с качеством 100%, 4:4:4; PNG — без потерь.
Исходное разрешение и детали сохраняются. Исходники не перезаписываются.
Веса V39 не менялись. Это оболочка проверенной модели, а не новая модель.
Сравнение «До / после»: нейтральный белый фон, общий масштаб, крупный просмотр.

Результаты и report.json находятся в выбранной папке отдельной серии.
Журнал: %LOCALAPPDATA%\ColorPro\logs\application.log.
Проверка компонентов в меню «Пуск» создаёт %LOCALAPPDATA%\ColorPro\diagnostics.json.
Удаление через «Приложения и возможности» сохраняет фотографии и результаты.

Установщик пока без цифровой подписи: Windows может показать предупреждение
SmartScreen о неизвестном издателе. Проверяйте происхождение и SHA-256 файла;
не отключайте защиту системы. Состав и лицензии — в third-party-licenses.
